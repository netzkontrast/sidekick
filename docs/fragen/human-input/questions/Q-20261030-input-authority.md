# Zuständigkeit für Antworten
Version: 1
Erstellt: 2026-10-30
Art: decision
Priorität: later
Kontext / Quelle: [Vision](../../../vision.md), Abschnitte 9, 11 und 13.
Anlass: Ein einheitlicher Vertrag für Menschen und Agents benötigt eine überprüfbare Antwort-Zuständigkeit; eine Antwort darf keine neue Befugnis erzeugen.
Auswirkung / blockierte Arbeit: spätere Human-Input-Spec; diese Skill-Implementierung ist davon unabhängig.
Fragestellung: Wer darf eine fachliche Antwort wirksam ersetzen, wenn Owner und Bearbeiter widersprüchlich antworten?
Optionen und Folgen: A: Ausschließlich Auftrag-Owner. B: Pro Frage benannter Verantwortlicher mit Owner-Eskalation. C: Jede berechtigte Person, Konflikte blockieren.
Empfehlung + sachlicher Grund: B; Zuständigkeit explizit halten und Konflikte sichtbar eskalieren.
Benötigter Sachbeleg: vor Interview aktuelle Entscheidungen auf bereits vorhandene Antwort prüfen.
