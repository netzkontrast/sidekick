# AGENTS.md – Wiki-Server

- Berichte auf Deutsch.
- Fremdcode unter `vendor/` wird nur gelesen.
- Der Wiki-Server wird als proprietäre Software an Kunden ausgeliefert, auch als gehosteter Dienst.
  Copyleft-Lizenzen (GPL, AGPL) sind für ausgelieferte Bestandteile ausgeschlossen.
- Wiki-Seiten haben bis zu 50 000 Zeilen; ein Vergleich zweier Fassungen muss auf einem Server mit 512 MB Arbeitsspeicher laufen.
- Neue Abhängigkeiten nimmt nur das Plattformteam auf. Recherchen empfehlen eine Kategorie und entscheiden nicht.
