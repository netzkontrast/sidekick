# AGENTS.md – Projekt „Abrechnungslauf“

Nächtliche Abrechnungsjobs für Kunden in Deutschland; Server laufen in UTC.

- Recherche nur lesend; keine Installation, keine Ausführung von Fremdcode.
- Bericht auf Deutsch. Belegstufen: dokumentiert, im Code gefunden, praktisch nachgewiesen, offen.
- Codeaussagen mit Datei und Zeile und gelesenem Stand belegen. Lizenz je Bestandteil getrennt erfassen.
- Über Abhängigkeiten entscheidet die Teamleitung Betrieb; Agents empfehlen nur.
