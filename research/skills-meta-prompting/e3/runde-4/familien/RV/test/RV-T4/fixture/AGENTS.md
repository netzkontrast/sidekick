# AGENTS.md – Projekt „Kassenbuch“

Importiert Kontoauszüge von Banken (CSV-Exporte bis etwa 2 GB) in die Buchhaltung.

- Recherche nur lesend; nichts installieren, keinen Fremdcode ausführen.
- Bericht auf Deutsch mit Belegstufen (dokumentiert, im Code gefunden, praktisch nachgewiesen, offen).
- Codeaussagen mit Datei und Zeile und gelesenem Stand belegen; Abwesenheitsaussagen mit Suchumfang.
- Über Abhängigkeiten entscheidet die Finanz-IT; Agents empfehlen nur.
